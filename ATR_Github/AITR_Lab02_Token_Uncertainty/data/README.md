# Dataset access
The experiment uses the QA configuration of `pminervini/HaluEval` via Hugging Face Datasets. Expected fields: `knowledge`, `question`, `right_answer`, `hallucinated_answer`. Check the live dataset card, schema, license, revision and date accessed before publication or redistribution.

Dataset card: https://huggingface.co/datasets/pminervini/HaluEval
Original project: https://github.com/RUCAIBox/HaluEval
Paper DOI: https://doi.org/10.18653/v1/2023.emnlp-main.397

The script downloads data at run time. Do not commit raw dataset files unless you have checked the terms and course requirements.
